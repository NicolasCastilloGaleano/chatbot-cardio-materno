# Prompts del producto (versionados)

Prompts del LLM **del producto** (no los del desarrollo). Cada prompt es un archivo `nombre.vN.md` con:
- propósito, entradas y formato de salida esperado;
- guardrails (no diagnosticar, no medicar, tono comunitario);
- historial de cambios y resultado de la evaluación con las conversaciones de referencia.

Un cambio de prompt es un cambio de comportamiento: aplicar la matriz de impacto (`docs/README.md`).
